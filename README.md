# 🤖 AI Resume Analyzer (React + Puter)

A lightweight, high-performance web application that analyzes resumes using AI. This version makes use of a streamlined **React Router** implementation, utilizing **Zustand** for global state management and **Puter.js** for cloud-native backend functionality.

---

### ⚡ Key Architectural Changes

* **Routing:** Managed via `react-router-dom` for seamless SPA navigation.
* **State Management:** Replaced heavy context providers with **Zustand** for a reactive, boilerplate-free store.
* **Cloud Infrastructure:** Powered by **Puter.js** (Cloud Storage, KV, and AI execution) to eliminate the need for a traditional backend.

---

### 🌟 Features

* **Cloud Analysis:** Leverages Puter's AI capabilities to process resume text.
* **Persistent Sessions:** Saves analysis history directly to Puter's cloud storage.
* **Atomic State:** Zustand-powered stores handle file uploads, analysis results, and UI themes.
* **Clean UI:** Minimalist design built with Tailwind CSS.

---

### 🛠 Tech Stack

| Category | Technology |
| :--- | :--- |

| **Routing** | React Router 7 |
| **State Management** | Zustand |
| **Backend/Cloud** | Puter.js |
